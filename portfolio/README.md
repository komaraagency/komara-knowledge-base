# 📸 Portfolio KOMARA AGENCY

Dépose tes images de réalisations ici. Le bot Telegram les listera
automatiquement dans le bouton 📂 Portfolio, et le client pourra
choisir laquelle voir.

## Convention de nommage
- Utilise des underscores ou tirets : `logo_resto_elegance.png`
- Le nom devient le bouton affiché : "📷 logo resto elegance"
- Formats acceptés : .png .jpg .jpeg .webp .gif

## Exemples
- `bot_restaurant_menu.png` → 📷 bot restaurant menu
- `logo_boutique_conakry.jpg` → 📷 logo boutique conakry
