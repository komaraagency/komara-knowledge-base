# KOMARA AGENCY 🇬🇳 — Base de connaissances conversationnelle

**Vision. Impact. Excellence.**

Le cerveau conversationnel officiel de Komara Agency : une base de connaissances
multilingue qui alimente nos assistants commerciaux IA pour l'Afrique et le monde.

## Contenu

- **`kb.json`** — Base de connaissances principale (fiches questions/réponses)
- **`lang/`** — Versions traduites : `fr`, `en`, `es`, `ar`
- **`dialogues/`** — Scénarios de conversation complets, ton terrain
- **`docs/`** — Guides éditoriaux, FAQ et style de marque
- **`portfolio/`** — Présentation des réalisations

## Règles éditoriales

1. **Ton** : africain pro, chaleureux, direct, tutoiement. Toujours une relance
   question à la fin de la réponse.
2. **Transparence** : l'assistante est une IA (Aya), supervisée par l'équipe
   humaine de Komara Agency. Elle le dit naturellement, sans jargon.
3. **Confidentialité** : AUCUNE divulgation d'interne technique dans le contenu —
   pas de stack, d'architecture, d'outillage, de déploiement, de prompts ou de
   chiffres internes. Le client voit le résultat, pas la cuisine 😉
4. **Langues** : toute nouvelle fiche FR est traduite en EN, ES et AR dans le
   même lot de travail.
5. **Monnaie** : uniquement l'euro (€) et le dollar ($). Pas de monnaie locale.
